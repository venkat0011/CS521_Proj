${objective}

TASO keeps a cost-ordered queue of whole candidate graphs. Each expansion pops
one graph, tries every rule enabled in the current phase, constructs matching
alternatives, and enqueues those passing the existing admission checks.

same complete rule set does not by itself meaningfully change this search.
